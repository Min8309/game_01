# 역사 게임 소품 이미지

`worn-hardcover.png`는 사용자가 제공한 낡은 갈색 하드커버 참고 이미지를 바탕으로 생성한 AI 게임 소품 텍스처입니다. 실존하는 『우맹』의 표지나 역사적 원본 자료가 아닙니다. 빈 표지 질감만 사용하고 책 이름·난이도는 게임에서 가까이 겨냥할 때 표시합니다.

`aged-expo-poster.png`는 사용자가 제공한 `search.pstatic.pdf`의 1929년 조선박람회 포스터를 바탕으로 채도 감소·종이 얼룩·접힌 자국을 적용한 AI 편집 게임 소품입니다. 역사 자료 원본의 복제본이 아니며, 세부 글자나 그림의 원문 확인에는 원본 자료를 사용해야 합니다. 캐비닛 옆 뒤쪽 벽에 부착합니다.

`hand-shadow.png`는 사용자가 제공한 벽의 손 그림자 참고 이미지를 바탕으로 생성한 투명 배경의 AI 공포 소품입니다. 철문 안 세 벽과 천장에 반복 배치하고 기울기·크기·위치를 변화시킵니다.

`hair-key.png`는 기존 AI 열쇠 이미지의 흰 배경을 제거한 AI 편집 소품입니다. 선반에서 획득하고 종이 위에 올려놓는 열쇠에 함께 사용합니다.
