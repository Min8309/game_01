# 경성야록 역사 기록 복원 게임

PC·모바일은 `/sikjasil/`에서 같은 공간과 문제를 사용합니다. PC는 WASD·마우스·E 조사, 모바일은 조이스틱·화면 드래그·픽업 버튼으로 조작합니다. 기존 공포·미스터리 연출과 음향을 유지하며 기본 모드는 시간제한 없는 자유 탐색입니다. 10분 도전은 시작 화면에서 별도로 선택합니다. 조사·안내·수첩을 읽는 동안 팝업과 발소리는 멈춥니다. 도전 모드의 제한시간은 읽기·종료·백그라운드 중에도 흐릅니다.

## 방별 필수 진행

1. 1층 식자실: 달력·24번 서랍·교정지·벽 포스터·캐비닛·복도의 책, 6개 역사 퀴즈와 괘종시계의 창작 공포 시간 퍼즐 1개(난이도 중), 총 7개.
2. 1층 철문: 7개 기록과 열쇠 획득을 완료하면 문이 열립니다. 출구방 정면 벽의 사건 지도를 조사해 열쇠를 삽입한 뒤, 현장 기록 네 곳을 시간순으로 연결해야 지하실 문이 열립니다. 경찰서 접수·감식 의뢰는 행정 기록이며 경로에 포함하지 않습니다. 지도 사건과 사진은 창작 소품입니다. 열쇠는 지도 잠금장치에 남습니다.
3. 지하 자료실: 중앙 책상과 선반의 책, 출처와 언어·문화 수호 문제 2개.
4. 암실: 손기정 보도사진의 의미를 읽는 문제 1개.
5. 사진 건조방: 심훈·오보·판결 자료의 해석 문제 3개.
6. 모든 방의 필수 기록 완료 → 마지막 사진 뒤집기 → 공포 예고 → 게임 종료.

난이도는 상·중·하로 표시합니다. 각 문제의 단서·3단계 힌트만으로 풀 수 있고 오답은 다시 시도할 수 있습니다. `진행 안내`(PC), `플레이 안내 → 방별 퍼즐·힌트 보기`(모바일), 수첩에서 남은 과제를 확인합니다. 모드별 진행을 같은 기기·브라우저에 자동 저장하고 시작 화면의 이어하기로 복원합니다.

복도의 책은 바닥에 놓인 낡은 하드커버 소품이며 제목은 가까이 겨냥할 때만 표시합니다. 캐비닛은 1층 뒤쪽 왼편에 있으며 세 번째 서랍을 열면 안쪽 역할표를 발견합니다. 서랍은 다시 조사하면 닫히고, 발견한 힌트는 소지품에 남습니다. 문제창은 질문·짧은 설명·선택지·힌트로 구성하고 정답 후에는 해설과 다음 조사 장소를 표시합니다.

탐색 중에는 작은 목표 표시만 유지합니다. 문제창은 화면 안에 고정하고 내용만 스크롤합니다. 초록 힌트는 평소 희미하게 보이고 가까이 겨냥하면 진해집니다. 모바일 조사 보조는 전방·거리·가림을 확인하며 뒤쪽이나 벽 너머의 물체를 선택하지 않습니다.

## 모듈

- `history-game.js`: 역사 문항·난이도·힌트·재시도·방 잠금·수첩·출구 안내.
- `hint-focus.js`: 시선·근거리 대상의 초록색 강조.
- `cabinet-prop.js`: 철제 캐비닛·서랍 애니메이션·역할표 발견.
- `exit-horror.js`: 철문 안 벽·천장 손 그림자와 방 안에서만 재생되는 낮은 배경음.
- `exit-room.js`: 정면 사건 지도와 인물 사진·붉은 실, 양옆 낡은 콘크리트 벽, 열쇠 삽입 소품.
- `exit-case-map.js` / `exit-case-map.css`: 창작 사건 자료·지도 위치·열쇠 잠금·경로 퀴즈·오답 재시도. `NODES`와 `ROUTE`로 문항을 확장할 수 있습니다.
- `assets/performance-controls.js`: 가까운 물체 검색·공유 시선 결과·프레임별 검색 제한·조명 및 해상도 조정.
- `room-puzzles.css`: 공통 조사창·목표 표시·공포 효과·사진 엔딩 스타일.
- `archive-space.js`: 자료실 입구·계단·책상·소품·충돌·공포 효과.
- `darkroom-space.js`: 암실·사진방·커튼·사진·조명.
- `missing-person.js`: 사진 기록 완료 상태와 마지막 공포 엔딩.
- `tension-director.js`: 위치 음향·사진 변화 연출.
- `archive-bootstrap.js`: 기존 3D 엔진과 지하 공간 연결.

구형 먹지·1124 스탬프·약품 순서·틀린그림 비교 UI와 독립 미리보기는 제거했습니다. 3D 공간·공포 연출에 필요한 엔진과 이미지·음향은 유지합니다. 신문 기사 작성자와 사건에 관여한 인물은 구분하며 미확인 세부 수치를 정답으로 사용하지 않습니다.

## 검증

저장소 루트에서 새 지도 퍼즐의 잠금·오답·재시도·전체 경로 조합을 확인합니다.

```sh
node --test tests/exit-case-map.test.cjs
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저 회귀 검증: PC의 기존 13개 문제와 새 지도 퍼즐, 열쇠 획득·지도 삽입·소모, 잘못된 경로 거부, 지하실·암실 개방과 엔딩을 확인했습니다. 모바일에서는 도구 버튼·수첩·픽업·캐비닛·벽 가림·거리 제한·타이머, 지도 퍼즐의 세로 화면 조작과 오프라인 재실행을 확인했습니다. Chromium 소프트웨어 WebGL에서 수행한 검증이므로 실제 휴대전화의 프레임 속도·설치·음향 청취는 별도 확인이 필요합니다.

## 자유 탐색·10분 도전

`game-session.js`는 모드별 localStorage 저장, 위치·소지품·문·지도·사진 상태 복원, 행동 기반 공포와 읽기 중 연출 중지를 담당합니다. 자유 탐색은 시간 초과 사망이 없습니다. 10분 도전은 시작 시각 기준 600초 미만에 14개 기록을 모두 완료해야 전용 호외 PNG·후일담·완주 배지를 지급합니다. 명시적 힌트 버튼을 누르지 않았으면 무힌트 기록관 칭호를 추가합니다. 최고 기록과 배지는 해당 브라우저에 보관하며 온라인 순위표가 아닙니다. 완료 화면은 자동으로 닫히지 않습니다.
