# 경성야록 역사 기록 복원 게임

PC·모바일은 `/sikjasil/`에서 같은 공간과 문제를 사용합니다. PC는 WASD·마우스·E 조사, 모바일은 조이스틱·화면 드래그·픽업 버튼으로 조작합니다. 기존 공포·미스터리 연출, 음향, 전체 10분 제한은 유지합니다. 조사·안내·수첩 중에도 시간은 흐르지만 무작위 귀신 팝업은 숨깁니다.

## 방별 필수 진행

1. 1층 식자실: 달력·24번 서랍·교정지·벽 포스터·캐비닛·복도의 책, 6개 역사 퀴즈와 괘종시계의 창작 공포 시간 퍼즐 1개(난이도 중), 총 7개.
2. 1층 철문: 힌트나 토글 없이 게임 7개와 머리카락 엉킨 열쇠 획득의 완료 여부만 표시합니다. 모두 완료되면 철문이 자동으로 열립니다. 안쪽 책상 위 종이에 열쇠를 올려놓으면 지하실 문이 자동으로 열리고, 열쇠는 소지품에서 빠져 종이 위에 남습니다. 입장 시 자동 안내창은 띄우지 않습니다.
3. 지하 자료실: 중앙 책상과 선반의 책, 출처와 언어·문화 수호 문제 2개.
4. 암실: 손기정 보도사진의 의미를 읽는 문제 1개.
5. 사진 건조방: 심훈·오보·판결 자료의 해석 문제 3개.
6. 모든 방의 필수 기록 완료 → 마지막 사진 뒤집기 → 공포 예고 → 게임 종료.

난이도는 상·중·하로 표시합니다. 각 문제의 단서·3단계 힌트만으로 풀 수 있고 오답은 다시 시도할 수 있습니다. `진행 안내`(PC), `플레이 안내 → 방별 퍼즐·힌트 보기`(모바일), 수첩에서 남은 과제를 확인합니다. 새로고침하면 진행이 초기화됩니다.

복도의 책은 바닥에 놓인 낡은 하드커버 소품이며 제목은 가까이 겨냥할 때만 표시합니다. 캐비닛은 1층 뒤쪽 왼편에 있으며 세 번째 서랍을 열면 안쪽 역할표를 발견합니다. 서랍은 다시 조사하면 닫히고, 발견한 힌트는 소지품에 남습니다. 문제창은 질문·짧은 설명·선택지·힌트로 구성하고 정답 후에는 해설과 다음 조사 장소를 표시합니다.

탐색 중에는 작은 목표 표시만 유지합니다. 문제창은 화면 안에 고정하고 내용만 스크롤합니다. 초록 힌트는 평소 희미하게 보이고 가까이 겨냥하면 진해집니다. 모바일 조사 보조는 전방·거리·가림을 확인하며 뒤쪽이나 벽 너머의 물체를 선택하지 않습니다.

## 모듈

- `history-game.js`: 역사 문항·난이도·힌트·재시도·방 잠금·수첩·출구 안내.
- `hint-focus.js`: 시선·근거리 대상의 초록색 강조.
- `cabinet-prop.js`: 철제 캐비닛·서랍 애니메이션·역할표 발견.
- `exit-horror.js`: 철문 안 벽·천장 손 그림자와 방 안에서만 재생되는 낮은 배경음.
- `exit-room.js`: 출구 방·낡은 테이블·매달린 조명·열쇠를 올려놓는 종이·실제 열쇠 소품.
- `room-puzzles.css`: 공통 조사창·목표 표시·공포 효과·사진 엔딩 스타일.
- `archive-space.js`: 자료실 입구·계단·책상·소품·충돌·공포 효과.
- `darkroom-space.js`: 암실·사진방·커튼·사진·조명.
- `missing-person.js`: 사진 기록 완료 상태와 마지막 공포 엔딩.
- `tension-director.js`: 위치 음향·사진 변화 연출.
- `archive-bootstrap.js`: 기존 3D 엔진과 지하 공간 연결.

구형 먹지·1124 스탬프·약품 순서·틀린그림 비교 UI와 독립 미리보기는 제거했습니다. 3D 공간·공포 연출에 필요한 엔진과 이미지·음향은 유지합니다. 신문 기사 작성자와 사건에 관여한 인물은 구분하며 미확인 세부 수치를 정답으로 사용하지 않습니다.

## 검증

저장소 루트에서 `python3 -m http.server 8000 --bind 127.0.0.1` 실행 후:

```sh
node --test tests/history-game.test.cjs tests/ghost-plan.test.cjs tests/missing-person.test.cjs
node tests/history-game-smoke.cjs
node tests/history-book-smoke.cjs
node tests/mobile-guide.cjs
node tests/mobile-pickup-assist.cjs
node tests/pwa-smoke.cjs
```

브라우저 테스트는 Node.js·Playwright·`/usr/bin/chromium`을 사용하고 순서대로 실행합니다. 다른 주소는 `GAME_TEST_URL`, 설치 모듈은 `PLAYWRIGHT_MODULE`로 지정합니다. 역사 게임 테스트는 PC와 모바일의 문제·힌트·오답 재시도·방 잠금·출구 안내·팝업 크기·힌트 밝기·엔딩을 검증하며 모바일은 실제 조이스틱으로 방 사이를 이동합니다. 자동화는 시점과 그래픽 해상도를 조정하고, PC 관찰 위치는 이동합니다. 실제 휴대전화의 성능·음향·설치는 별도 확인이 필요합니다.
